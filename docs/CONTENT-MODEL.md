# Content glossary and template contract

| Term | Meaning |
| --- | --- |
| Drawing | One gallery work, potentially represented by multiple images. |
| Article | Longer-form writing, independently addressable. |
| Note | Short-form writing; published content, not synonymous with draft. |
| Tag | Overlapping subject filter: Drawing, UI, Tech, Programming initially. |
| Draft | Authoring state excluded from published lists and routes. |
| Featured | Explicitly selected drawing for the homepage. |
| Related | Explicit link between drawing, writing or project; not inferred from invented content. |
| Experiment | Operable generative canvas, separate from authored gallery work. |

## Proposed template fields
Writing: slug, title, kind (article/note), date, language, tags, summary, draft, related; Markdown body.
Drawing: slug, title, description, featured, draft, related, images (src, alt, optional caption); optional Markdown body.

These are design contracts, not a working publishing pipeline. No entries are fabricated. Template implementation and validation follow visual selection.
