# ADR 002 — Select A and remove the experiment

Status: accepted; supersedes homepage experiment and A/B selection in ADR 001.
Date: 2026-10-20

The user prefers A but finds the canvas and console unsuitable. Remove generated artwork, controls, instructions, animation/pointer logic and B comparison from the active prototype. Retain A typography, charcoal/lime palette, navigation, introduction, Gallery/Writing entrances, honest empty states and existing Projects/About destinations. Reflow the introduction into two columns on desktop and one on mobile; content follows immediately.

This is a prototype revision, not production integration. Original A/B screenshots remain historical review evidence only. Future interactive experiments are not part of the current scope.
