# Selected A prototype

Run `npm run dev -- --host 127.0.0.1`, then open `/prototypes/index.html` on the printed origin.

The user selected A and then removed the canvas and console. The active prototype contains the introduction, Gallery and Writing entrances/empty states, existing Projects/About links and a persistent light/dark toggle. Old variant query links resolve to the selected layout. No canvas code or animation loop remains.

This HTML is a local design study, not included as a production build entry. Markdown publishing and full content detail integration are deferred. Production React pages are unchanged. Google Fonts supplies Barlow/Barlow Condensed with sans-serif fallback. Preview defaults dark; eventual production will follow system preference initially.

Screenshots in review/ are local verification artifacts and are excluded from Git. They are not required to run the prototype; create fresh captures when checking a change.
